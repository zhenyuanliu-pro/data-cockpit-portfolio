## 项目简介

为一家多主体医疗器械销售集团（4 家关联公司）打造的经营数据驾驶舱：自动同步金蝶云星辰四账套业务数据（销售 / 退货 / 收款 / 未结清单据），在统计层抵销关联方内部交易虚增，聚焦「卖了多少、钱什么时候回来、哪些账有风险」三个经营核心问题。

## 核心亮点

- **净额口径引擎**：四家关联主体之间的内部交易自动抵销，修正最高 86% 的应收虚增
- **账龄 × 超期双口径**：区分「欠了多久」与「逾期多久」（基于单据到期日），梯级坏账拨备预估 + 账龄迁徙预警
- **双基准 KPI**：目标达成率 vs 时间进度刻度线、行业基准对标、同比动量
- **三级预警 → 处置工单**：高危 / 关注 / 监控分级，一键生成带责任人与处置建议的催收工单
- **增量同步引擎**：HMAC-SHA256 签名鉴权、token 生命周期管理、修改时间水位线 + 幂等 upsert
